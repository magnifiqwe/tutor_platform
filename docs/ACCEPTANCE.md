# Приёмка перед первым уроком

## Автоматически

```bash
npm ci
npm run check
npm test
npm run build
```

Тесты используют временные базы и порты 3198/3199. Реальный `data/platform.sqlite` не затрагивается. Тест Python действительно загружает CPython/WASM и проверяет `input`, импорт своего модуля, стандартные библиотеки, чтение/запись файлов и команды Turtle. Он не заменяет браузерный тест iframe / SharedArrayBuffer.

## В двух браузерах / профилях

- [ ] Открыть платформу через HTTPS. Оба домена имеют валидный сертификат.
- [ ] Войти преподавателем; создать тестового ученика с отдельным логином и паролем.
- [ ] В другом профиле браузера войти учеником. Ученик не видит цены, других учеников и CRM-заметки.
- [ ] Записать покупку 4 × 60 минут; создать 4 будущих урока с оплатой из неё. Пятый оплаченный урок из того же пакета отклоняется.
- [ ] Открыть сессию первого урока. Доску одновременно видят оба.
- [ ] Добавить текст и фигуры с обеих сторон; перезагрузить ученика и проверить сохранение.
- [ ] Одновременно печатать в `main.py`, видеть курсоры и итоговый общий текст без потерь.
- [ ] Преподавателю добавить `helper.py` и `numbers.txt` из примера. Ученику нет кнопки добавления файла.
- [ ] Выполнить `examples/main.py`, ввести число. Оба видят консоль и квадрат. Скачать `result.txt` и проверить сумму 30.
- [ ] Записать файл программой, запустить повторно и прочитать его. Изменение должно сохраниться.
- [ ] Запустить `while True: pass`, нажать «Стоп». Интерфейс продолжает отвечать.
- [ ] Начать параллельный пробный урок второго ученика. Переключать комнаты; доски, код и вывод не смешиваются.
- [ ] Закрыть доступ первому ученику. Доска и код доступны только для просмотра; повторный запуск недоступен.
- [ ] Завершить урок со списанием. Баланс 3, урок помечен как списанный; повторное завершение не списывает второй раз.
- [ ] Провести бесплатный пробник: баланс неизменен.
- [ ] Отменить будущий урок без списания: его резерв освобождается. Позднюю отмену списать вручную и проверить отдельный статус.
- [ ] Загрузить `examples/lesson.md`. Отдельно попробовать заметку с картинкой `![[имя.png]]` и загрузкой этой картинки.
- [ ] Выдать домашку; ученик отправляет текст/ссылку. Проверить оценку, комментарий, доработку и историю попыток.
- [ ] Заблокировать ученика: текущая сессия отзывается и новый вход невозможен.
- [ ] Перезапустить сервер, проверить сохранённые доски, код, оплаты и уроки.
- [ ] Проверить доступ из домашней и мобильной сети ученика в России.

## Статус в среде разработки

- TypeScript: проверяется командой `npm run check`.
- Production-сборка: проверяется командой `npm run build`.
- Автоматические тесты: результат текущего запуска сообщён вместе с передачей проекта.
- Браузерная, визуальная, VPS/Docker и нагрузочная проверки: не выполнены в этой среде. Эти пункты не помечены как пройденные.
